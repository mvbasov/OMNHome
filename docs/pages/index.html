Page library

Ready-made pages for OMN-Go. A page is one Markdown file with its own HTML and script. Download a page, add it to OMN-Go, and open it like each other note. How to add a page.



A page script has full rights. It can change or delete each note and each file of OMN-Go. Add only a page that you trust. Each page here is plain text: read it before you add it.

The pages need OMN-Go 26.11.10 or newer. To save a file, a page needs the admin. On your own device you are always the admin.



Color schemes

v26.11.11

An editor for color schemes. A scheme sets new values for the light palette and the dark palette of OMN-Go. It can also set the main font and the code font. A color picker sets each color and shows the contrast of each text and background pair. It can set the lightness to meet WCAG AA or AAA. Examine the scheme in the preview, then apply it. You can export and import the schemes.

Import and apply the scheme

  1. Add the Color schemes page to OMN-Go (how), and open it.
  2. Press  Import schemes to open the import panel.
  3. On a phone: press Copy JSON on this page, then paste the text into the field of the panel.
    On a desktop: you can also press  and select the downloaded file pastel-amber-hercules.json.
  4. Press  Import the pasted JSON, and confirm. An imported scheme replaces a scheme with the same name.
  5. On the card Pastel Amber Hercules, press  Apply. The colors and the fonts change at once. You do not have to start OMN-Go again.


The OMN-Go editor does not load omn-go-custom.css. It keeps the default colors, thus a bad scheme cannot keep you out of it.

To go back to the OMN-Go colors, press Remove the applied scheme on the Color schemes page.

Adapter for old pages

v26.11.10

OMN-Go 26.11.7 gives each color token, class and id of the application the prefix omn-. For example, --bg is now --omn-bg, and the class bg-yellow is now omn-bg-yellow. OMN-Go 26.11.10 also renames the panel classes, for example omn-config-panel to omn-card. A page made before these versions then loses some of its colors and styles.

This page makes an adapter for the old names from the stylesheets of the installed version. It puts the adapter into css/omn-go-custom.css, checks it, and removes it when no page needs it.

Use the adapter

  1. Add the page to OMN-Go (how), and open it.
  2. Press Make, and read the adapter text.
  3. Press Put. The page writes the adapter into css/omn-go-custom.css and checks it.
  4. After each update of OMN-Go, open the page again and press Check. If the check finds a difference, press Put again.
  5. When no page uses the old names, press Remove.


The adapter cannot change a script or an id. Edit these old names in your page: #preview → #omn-preview, #content → #omn-content, #status → #omn-page-footer, quickPanel → omn-quick-panel, and classList.remove('hidden') on an OMN-Go element → classList.remove('omn-hidden').
