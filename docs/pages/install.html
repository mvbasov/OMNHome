Add a page to OMN-Go

A page is one Markdown file (.md). There are three ways to add it, on Android and on the desktop. Each way works with each page of the library.

 Android

Open the file in OMN-Go easiest

OMN-Go receives the file as a note from another person.

  1. In the page library, press Download. The browser saves the file in Downloads.
  2. Open the file: press the download notification, or open the file in a file manager.
  3. In the list of applications, select OMN-Go. If OMN-Go is not in the list, press Share and select OMN-Go there.
  4. OMN-Go saves the page below incoming/ and opens it. The Incoming notes page also gets a link to it.

Paste the text into a new page

You select the name and the place of the page.

  1. In the page library, press Copy text.
  2. In OMN-Go, press the page title to show the header buttons, then press  New page.
  3. Enter a name, for example ColorSchemes, and confirm it. The new page opens in the editor.
  4. Select all the text in the editor, and paste. The text of the library page replaces the header block that OMN-Go made.
  5. Press  Save.

Put the file into the notes directory

For a file manager that can write to the media directory of an application.

  1. Download the file.
  2. Move it into the md/ directory of OMN-Go:
    /storage/emulated/0/Android/media/net.basov.omngo/md/
    For the F-Droid build, the directory is …/Android/media/net.basov.omngo.fdroid/md/.
  3. Add a link to the page in a note, for example [Color schemes](/ColorSchemes) on your Welcome page. Press the link. OMN-Go compiles the page the first time you open it.

 Desktop

Receive the file easiest

OMN-Go receives the file as a note from another person.

  1. In the page library, press Download. The browser saves the file in your download directory.
  2. In OMN-Go, open the Incoming notes page. The Welcome page has a link to it. With the default port, its address is http://localhost:8080/incoming/incoming.
  3. Press Receive a note. Select the file, or drop it on the box.
  4. Press Import. OMN-Go saves the page below incoming/ and puts a link to it at the top of the list.

Paste the text into a new page

The same as on Android: press Copy text in the library, press  in OMN-Go, enter a name, select all the text in the editor, paste, and save. With an external editor, paste into the file that it opens.

Put the file into the notes directory

Save or copy the file into data/md/, next to the OMN-Go executable. Then add a link to the page in a note, for example [Color schemes](/ColorSchemes), or open http://localhost:8080/ColorSchemes.

After you add a page



Read "How this page works"

Each page of the library starts with this panel. It tells what the page does, which files it writes, and what each button does. The version of the page is at the right of the panel title.



Update a page

A received note never writes over a note: a second import makes a second page, for example ColorSchemes-2. To update, open the page you have, press Edit, replace all the text with the new text, and save. Or replace the file in md/. The data of the page stays in its own files.



Other devices

A page is a normal note. Git sync sends it to your other devices, and the data files of the page go with it. You can also send the page from OMN-Go with Send this note in the metadata panel.



A page script has full rights. It can change or delete each note and each file of OMN-Go. Add only a page that you trust. To save a file, a page needs the admin. On your own device you are always the admin. From another device on your network, log in with the admin password first.
